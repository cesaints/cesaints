## Selected public work

Two repositories offer a focused starting point for reviewing my work.
Each has a specific scope and visible limitations.

### [NexusData](https://github.com/cesaints/nexusdata)

An asynchronous data-processing project using **FastAPI, Celery, RabbitMQ
and PostgreSQL**. Designed around tenant-scoped processing, idempotency and
signed webhooks. The processing adapter is currently a mock. See the
repository README for implementation details and current project status.

### [Marketing Digital](https://github.com/cesaints/marketing-digital)

A **Next.js and TypeScript MVP** for simulating ROI, ROAS and CAC from supplied
inputs. Products and simulations persist in the browser; live advertising
analytics are not integrated. The figures are calculations based on the
user's assumptions, not measured campaign results.

These projects show different concerns: processing work across services,
and making business calculations understandable in an interface. My other
repositories document learning exercises and experiments.
